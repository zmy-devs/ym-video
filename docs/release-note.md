## 7.1.0

- 重构播放器布局与共享控件状态，统一双端手势、进度和快捷键交互。
- 控件隐藏时显示底部 1px 黄色进度条，轨道透明；修复 Windows 全屏播放时细进度条被视频遮挡的问题。
- 移动端缩放画面时保持控件原有显隐状态，右上角提供小尺寸、不透明背景的还原按钮，并调整控件间距与左右安全区。

- 统一登录、注册、账号设置、播放源和管理端表单校验，字段错误直接显示在对应输入项下。
- 优化影片卡片长按、海报加载状态、双端问候和播放源分组，整理移动端标题栏与导航布局。
- 优化客户端更新检查、下载与安装状态，检查结果和失败统一通过提示消息反馈。
- 调整 Android 开屏图标安全间距与透明底色，完整显示图标边框；调试版使用独立名称与包名，可与正式版同时安装，并适配本地更新流程。
- 按职责整理请求入口、数据校验、公共类型和工具函数，启用 TypeScript 未使用变量与参数检查。
